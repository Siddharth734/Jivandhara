# Running

The README launch command is:

```text
python main.py
```

Run it from `code/`, because `main.py` imports sibling modules as top-level modules and runtime paths such as `graphics/`, `audio/`, and `map/` are relative to the current working directory.

The game creates a resizable 1280x720 window titled `Jivandhara`. F11 toggles fullscreen. Close the window to exit. ESC toggles the upgrade/pause mode during play.
