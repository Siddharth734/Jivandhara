# Gameplay Mechanics

The implemented gameplay loop is an open-world-style top-down action prototype: the player moves through a CSV-authored map, fights nearby monsters with weapons and magic, collects experience from kills, and spends experience in the upgrade overlay.

Implemented mechanics include directional movement, collision with map obstacles, directional weapon attacks, healing, flame effects, enemy chase/attack radii, health and energy, temporary invulnerability, knockback, particles, experience, and stat upgrades.

The README mentions additional characters, bosses, jumping, and mouse controls, but those are not implemented in the inspected runtime path and should not be treated as current mechanics.
